## About

StashFerret is an open-source, lightweight tool for saving and organising reading, research, and web exploration, while keeping your main Zotero library focused on the material that matters most.

## Features

- Save stable reading copies as HTML or PDF
- Organise saved items conveniently in a browser-based, bookmark-style tree
- Preserve key bibliographic information such as date accessed and original URL
- Seamlessly send items to Zotero
- Create manual backups and restorable cloud backups

## SingleFile credit

StashFerret incorporates parts of [SingleFile](https://github.com/gildas-lormeau/SingleFile) for saving complete webpages. Thank you to SingleFile's creator, Gildas Lormeau, and to its contributors for making the project available.
