  Collect first. Organize in Zotero later.
</p>


## Features

- Save stable reading copies as HTML or PDF
- Organise saved items conveniently in a browser-based, bookmark-style tree
- Preserve key bibliographic information such as date accessed and original URL
- Seamlessly send items to Zotero
- Create manual backups and restorable cloud backups

## SingleFile credit

StashLibrary incorporates parts of [SingleFile](https://github.com/gildas-lormeau/SingleFile) for saving complete webpages. Thank you to SingleFile's creator, Gildas Lormeau, and to its contributors for making the project available.
