# \# SingleFile Provenance

# 

# StashLibrary bundles unmodified runtime files from SingleFile version 1.22.98.

# 

# Upstream project:

# https://github.com/gildas-lormeau/SingleFile

# 

# Official Firefox release:

# SingleFile 1.22.98

# Released 24 February 2026

# 

# Verification:

# The bundled SingleFile runtime files in StashLibrary were compared against the

# official SingleFile 1.22.98 XPI distributed by Mozilla Add-ons.

# 

# The following files matched the official release byte-for-byte by SHA-256:

# 

# \- chrome-browser-polyfill.js

# \- single-file-background.js

# \- single-file-bootstrap.js

# \- single-file-extension-core.js

# \- single-file-extension-frames.js

# \- single-file-frames.js

# \- single-file-hooks-frames.js

# \- single-file.js

# 

# The bundled chrome-browser-polyfill.js corresponds to the runtime file from

# SingleFile's lib directory.

# 

# StashLibrary does not modify these vendored SingleFile files. StashLibrary-specific

# integration is implemented separately in StashLibrary-owned files such as

# background.js and manifest.json.

# 

# Licensing information for SingleFile is retained in:

# 

# \- vendor/singlefile/SINGLEFILE-LICENSE.txt

# \- vendor/singlefile/SINGLEFILE-NOTICE.txt
