Welcome to StashLibrary

StashLibrary automatically keeps your local library in your configured storage folder. Open ⚙ Settings to view it, then optionally set up Cloud Backup.

Save a page or PDF locally: right-click in the bookmark area and choose Add Bookmark. StashLibrary stores the original URL and the time you saved it, so that date can later become Zotero's Accessed date.

Send something straight to Zotero: click Send to Zotero. Pick a Zotero folder, then click Save. Nothing is sent before you confirm.

Useful extras: bookmarks open in a new tab; Ctrl+click selects individual items; Shift+click selects a range; Ctrl+Z / Ctrl+Y undo and redo; you can migrate selected Zotero folders into StashLibrary, send archived items back to Zotero, drag/reorder items, and keep an optional cloud backup.

Favicons

Refresh Favicons checks each bookmark's website for a newer icon. When a new icon is found, StashLibrary saves it for offline use. If a website is unavailable or no replacement can be downloaded, StashLibrary keeps the existing favicon.

Existing favicons are never removed when a refresh fails.
